# Mickey Hub media

[Project guide](../) · [File and verification guide](../docs/BUILD.md)

![Mickey Hub rotating and separating into labeled assemblies](mickeyhub-preview.gif)

The 55.5-second looping GIF shows the complete rotating decomposition at twice
the original speed. Twenty chapters introduce 46 assemblies with English labels,
explanations and close-ups. It has no narration.

| File | Purpose |
| --- | --- |
| [Animated preview](mickeyhub-preview.gif) | The 960 × 540 GIF displayed in the project README. |
| [Enclosure preview](mickeyhub-preview.png) | The approved graphite finish and unchanged light ring. |
| [Storyboard](mickeyhub-animation.json) | English chapter sequence, module descriptions and timing. |
| [Captions](mickeyhub-animation.srt) | English chapter labels with timestamps. |
| [Final integrated assembly](../mickeyhub.blend) | The project's single included Blender file. |

The full 111-second MP4 is stored locally at
`memory_backups/videos/mickeyhub/mickeyhub-animation.mp4` relative to the
repository root. The separate animation Blender file and rendering tools are
under `memory_backups/3d_sources/`. Both archives are excluded from commits.

The included GIF can be viewed directly without Blender or the local archive.
Its dimensions, timing and SHA-256 are recorded in
[preview.json](../validation/preview.json). The build guide explains how to
verify the public files without requiring the archived animation or video.
